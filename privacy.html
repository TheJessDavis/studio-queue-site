Studio Queue Privacy Policy

Effective August 25, 2026

Studio Queue is a personal content planning application operated by its sole user and owner, Jess Davis. It is not offered to the public. This policy describes how the application handles data.

What the app does

Studio Queue helps its owner plan, film, schedule, and analyze short-form video content for social media accounts that she owns and operates.

Data the app accesses

  • With the owner's explicit authorization through each platform's official login flow, the app reads the owner's own profile information, video list, and video performance statistics.
  • The app never accesses data belonging to any other person or account.

How data is stored

All data is stored in a local database on the owner's own computer. Nothing is transmitted to third parties, sold, shared, or used for advertising. Aggregated performance context may be sent to the Anthropic API solely to generate content suggestions for the owner; Anthropic does not train on this data.

Data deletion

The owner can delete all stored data at any time by deleting the application's local database file, and can revoke the app's platform access at any time from each platform's security settings.
